= Shortcut Keys =


'''Note:''' LMB, MMB and RMB are the short for Left, Middle and Right Mouse Button, respectively.


<br /> 


'''<u>Editor and File</u> ''' 


'''Ctrl + S''' – Save the map. <br /> '''Ctrl + Z''' – Undo. <br /> '''Ctrl + Y''' – Redo. <br /> <br /> '''Alt + F4''' – Close Editor. <br /> '''Esc''' – Close Editor (Only if not obtruded by, for example, a dialogue box).


<br /> 


'''<u>Tools and Navigation </u> ''' 


'''1''' through '''0''' – Select Editor tools (the first 10 tools from top to bottom). <br /> '''Ctrl+1''' or '''2''' – Select Editor tools (The last two tools in the toolbar). <br /> <br /> '''Alt + LMB''' – Rotate view. <br /> '''Alt + MMB''' – Move center point (or pan view, as you prefer to put it). <br /> '''Alt + RMB''' (Zoom). <br /> '''Mouse Scroll wheel'''- Zoom in/out.


<br /> 


'''<u>Editing</u> ''' 


'''Q, W''' – Rotates an object along the Y axis, while placing them in the map. <br /> '''Q, W, E''' – Selects the transformation gizmos (Translation, Rotation and Scale, respectively), when the Select Tool is active. <br /> <br /> '''Shift + LMB''' – Add to/subtract from selection. (When clicking on, or box selecting objects). <br /> '''Ctrl + LMB''' – Subtract from selection (When clicking on, or box selecting selected objects). <br /> <br /> '''Space''' – Expand/Contract active viewport. <br /> '''F''' – Focus viewport on selection (zoomed in). <br /> <br /> '''G''' – Show grid.


<br /> 


'''<u>Objects </u> ''' 


'''Ctrl + F''' – Find Objects. <br /> '''Ctrl + D''' – Duplicates the selected object (In the exact same position as the original). <br /> '''D''' – Alternatively, holding D and dragging an object with the translation gizmo will create a duplicate object. <br /> '''B''' – Group objects. <br /> '''Delete/Backspace''' – Delete selected Object(s).
